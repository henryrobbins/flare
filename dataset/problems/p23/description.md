A network consists of n nodes (customers), each pair of which has a known service cost. The cost from any node to itself is zero, and the cost between any two distinct nodes is strictly positive. The full set of pairwise costs is provided as an n-by-n matrix. An integer p, strictly between zero and n, specifies how many of the n nodes must be selected as facility sites (called medians). Every node, including those chosen as medians, must be served by exactly one open median. The cost of serving a node is the cost from that node to the median it is assigned to; a node chosen as a median serves itself at zero cost. A node may only be assigned to a node that has been selected as a median. The goal is to choose exactly p nodes as medians and assign every node to one of those medians so that the total service cost, summed over all n nodes, is as small as possible.
